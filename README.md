# Español SRS

Особистий PWA-тренажер іспанської мови з інтервальним повторенням (спрощений SM-2, як в Anki).

## Структура файлів

- `index.html` — точка входу
- `style.css` — весь дизайн
- `app.js` — логіка: SM-2 алгоритм, збереження даних, рендер
- `manifest.json` — налаштування PWA (іконка, назва, кольори)
- `sw.js` — service worker для офлайн-роботи
- `icons/` — іконки застосунку

## Як запустити локально

1. Відкрий цю папку у VS Code
2. Встанови розширення **Live Server** (Ritwick Dey), якщо ще не встановлено
3. Клікни правою кнопкою на `index.html` → **Open with Live Server**
4. Застосунок відкриється в браузері на `http://127.0.0.1:5500`

## Дані зберігаються локально

Усі картки та прогрес зберігаються в `localStorage` браузера — тобто прямо
на твоєму пристрої. Якщо очистиш дані браузера — прогрес зникне (це нормально
для MVP; синхронізацію між пристроями можна додати пізніше).

## Що можна покращити далі

- Перенести дані з `localStorage` в `IndexedDB` (більше місця, надійніше)
- Додати аудіо-вимову слів
- Додати можливість імпорту/експорту колод (JSON-файл)
- Синхронізація між пристроями через власний бекенд або Firebase
